- [ ] Complete Google Search Console Domain Verification (via DNS TXT record).

- [ ] Submit `https://baxtiyorhealthcare.com/sitemap.xml` in Bing Webmaster Tools.
- [ ] Submit `https://baxtiyorhealthcare.com/sitemap.xml` in Yandex Webmaster Tools.
- [ ] Perform URL Inspection on `/en`, `/ar`, `/en/treatments/kidney-transplant-india`, and `/en/countries/uzbekistan` to request prioritized indexing.
- [ ] Update table column `Indexing Status` to `[INDEXED]` as Googlebot confirms coverage.
